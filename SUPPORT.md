# Getting help

Need help with npm-switchyard? Here's where to look, in order:

1. **Read the docs**: the [README](README.md) gives an overview and links to everything else.

2. **Search existing issues**; your question may already be answered:
   <https://github.com/motwok/npm-switchyard/issues?q=is%3Aissue>

3. **Open an issue** if you don't find an answer:
   - [Bug report](https://github.com/motwok/npm-switchyard/issues/new?template=bug_report.yml)
   - [Feature request](https://github.com/motwok/npm-switchyard/issues/new?template=feature_request.yml)

## Please note

- **Security problems** are **not** reported as public issues; see [SECURITY.md](SECURITY.md) for
  private reporting.
- **Pull requests are welcome**; see [CONTRIBUTING.md](CONTRIBUTING.md).
- This is a single-maintainer project, so help is best-effort. Thanks for your patience.
